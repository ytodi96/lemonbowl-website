The Lemon Bowl — static website snapshot
=======================================
Open index.html in any browser (double-click) or serve the folder locally:
  python3 -m http.server 8000   ->  http://localhost:8000

Pages included: Home, Menu (Order), Cart, Catering (+ Build Your Own, Quote),
Occasions (+ Subscription), Gifting, About (+ Founders, Mission), Gallery,
Reviews, FAQ, Contact, Privacy, Terms, Refunds.

Notes:
- This is a visual snapshot: photos and styling are embedded in the folder,
  internal navigation links work between pages.
- Interactive behaviour (add-to-cart, filters, forms) is not active in the
  snapshot — use the live site for that.
- Fonts and the embedded map load from the internet when available.
